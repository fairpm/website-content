# Packages for TYPO3

Browse TYPO3 extensions distributed through FAIR's federated package network.

## Current status

FAIR support for TYPO3 is currently under active development. The TYPO3 Core Team, led by Benni Mack, is working on integrating the FAIR protocol into TYPO3's Extension Repository (TER) and Extension Manager. This work was initiated as part of the TYPO3 Community Budget 2026 and is being prototyped at the CloudFest Hackathon 2026.

Once complete, this integration will allow TYPO3 to:

- Browse and install extensions served through FAIR Aggregators, either within TYPO3 core or as a standalone extension.
- Discover extensions from multiple sources — including Composer, TER, and individual repositories with FAIR Beacon.
- Verify packages through FAIR's cryptographic signing and Decentralized Identifiers (DIDs).
- Benefit from supply chain transparency in line with the EU Cyber Resilience Act.

We will update this page as the integration matures. If you'd like to follow along or contribute, join the conversation on [Slack](https://chat.fair.pm) or check out the project on [GitHub](https://github.com/fairpm).
